# Student Management System

A console-based Student Management System developed using C programming. This project helps manage student records through a simple menu-driven interface.

## Features

- Add new student records
- View all student records
- Search for a student by ID
- Update student information
- Delete student records
- View student results
- Calculate average marks
- Store and retrieve student data using file handling

## Technologies Used

- C Programming
- Structures
- Functions
- File Handling
- Loops and Conditional Statements

## Student Information

The system manages the following details:

- Student ID
- Student Name
- Age
- Marks

## How to Compile and Run

1. Install a C compiler, such as GCC.
2. Open the project folder in your terminal.
3. Compile the source file:

   `gcc main.c -o StudentManagement`

4. Run the program:

   **Windows:**
   `.\StudentManagement.exe`

   **Linux/macOS:**
   `./StudentManagement`

5. Choose an option from the menu and follow the instructions.
