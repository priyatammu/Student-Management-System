# Student Management System

A simple console-based Student Management System developed in C.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Student Results
- Calculate Average Marks
- Store student data using file handling

## Technologies Used

- C Programming
- File Handling
- Structures
- Functions
- Loops and Conditional Statements

## How to Run

1. Compile the `main.c` file using a C compiler.
2. Run the generated executable.
3. Select an option from the menu.
4. Follow the instructions displayed in the terminal.

## Student Information

The system manages:

- Student ID
- Student Name
- Age
- Marks

## Project Type

Console-based application built as a beginner C programming project.
